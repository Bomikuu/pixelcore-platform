# Smokey reporting workspace

Mode: Operate. Audience: business owners, administrators and managers reviewing
recorded daily activity. Authority: approved Smokey design spec and existing
PixelCore workspace design system. This is a local extension, not a new identity.

## Direction contract

THESIS: Ask for a business briefing, then inspect its authoritative facts and source
records. Chat is the entry point; the saved report is the durable result.
OWN-WORLD: White-first host surfaces, existing Manrope typography and business
accents, semantic workspace tokens, canonical shadcn controls and restrained borders.
STORY: Enable, connect and verify a provider, choose a companion, ask, inspect, save
and revisit without another provider charge.
FIRST VIEWPORT: Page title and theme control, stable section navigation, then the
current task. Overview presents the existing mascot, a useful explanation and Ask
Smokey; report pages begin with the date/timezone and factual totals.
FORM: Existing workspace extension chosen by the approved brief; drawer and modal
share a single controller. No concept seed is required for this specified extension.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## State and verification contract

Status follows actual server phases. Custom static mascots and reduced-motion
users receive equivalent text; no invented percentages. Private snapshots, source
links and explicit unavailable information protect factual interpretation.

Independent static review scored its five findings resolved after fixes. Automated
controller, API and PostgreSQL race checks are recorded in docs/smokey-assistant.md.
Browser/visual verification and production builds were not authorized. The existing
mascot raster is reused from SmokeyChatbot/backend/core/assets/office-cat-sprite.webp;
no raster was generated or edited for this feature. Existing DESIGN.md and its
runtime theme owner remain authoritative; the new module introduces no global
PixelCore palette or font change.
